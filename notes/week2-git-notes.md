## 1. 核心概念
- **工作区**：我们当前写代码的文件夹。
- **暂存区**：存放通过 `git add` 添加的改动。
- **本地仓库**：存放通过 `git commit` 提交的版本。
- **远程仓库**：存放在 GitHub 上的云端仓库。

## 2. 本周常用核心命令
- **`git clone <仓库地址>`**：将远程仓库的项目克隆到本地电脑。
- **`git checkout -b <分支名>`**：创建并切换到一个新分支。
- **`git add <文件名>`**：将指定文件添加到暂存区。
- **`git commit -m "提交说明"`**：将暂存区的改动提交到本地仓库。
- **`git push origin <分支名>`**：将本地分支的提交推送到远程 GitHub 仓库。
- **`git status`**：查看当前工作区和暂存区的状态。
- **`git log`**：查看提交历史记录。
